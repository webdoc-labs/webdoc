# @webdoc/language-parser

This package parses a file and outputs it documentation tree.

## Legacy package status

`@webdoc/parser` 1.6.6 is a legacy package and receives no further releases.
Use this Rush-managed successor, `@webdoc/language-parser`, for supported
Webdoc 2.x integrations. Replace the `@webdoc/parser` dependency and imports
with `@webdoc/language-parser` when upgrading; do not add new dependencies on
the legacy package.
