# @webdoc/language-parser

This package parses a file and outputs it documentation tree.

## Legacy package status

`@webdoc/parser` 1.6.6 is a legacy package. Its maintenance and npm
deprecation decision remains with the repository owner; this notice does not
deprecate it. For new Webdoc 2.x integrations, use the Rush-managed
`@webdoc/language-parser` package. Existing consumers should plan a migration
and validate API compatibility and tests before changing dependencies or
imports; do not add new dependencies on the legacy package.
